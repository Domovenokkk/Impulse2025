# Проект для генерации конфигурационных файлов

Этот проект представляет собой решение для генерации конфигурационных файлов на основе XML-модели, а также для сравнения и обновления конфигурационных данных. Он предназначен для работы с данными базовой станции, где используется описание классов и их атрибутов, а также агрегации между ними.

## Описание

Программа выполняет следующие задачи:

1. **Генерация конфигурации (config.xml):** 
   - Программа парсит входной XML-файл модели, создавая структуру данных, которая соответствует базовой станции.
   
2. **Создание мета-информации (meta.json):**
   - Программа генерирует файл `meta.json`, который содержит описание классов и их атрибутов, используемый фронтендом для отображения данных в интерфейсе пользователя.

3. **Сравнение конфигураций и генерация дельты (delta.json):**
   - Программа сравнивает два JSON-файла конфигураций: `config.json` и `patched_config.json`. На основе различий между ними создается файл `delta.json`, который содержит добавленные, удаленные и обновленные параметры.

4. **Применение дельты к конфигурации (res_patched_config.json):**
   - На основе файла `delta.json` программа обновляет исходную конфигурацию и сохраняет результат в файл `res_patched_config.json`.
